# 命令协议（v0.2.0）

USB CDC／BLE NUS 使用当前官方 ChameleonUltra 帧和全部官方命令，管理协议版本 2.2。类型 ID 与卡片格式直接采用官方定义：EM410X=100，Mini/1K/2K/4K=1000/1001/1002/1003。不要向 1005 发送旧的二字节类型请求；新请求为 slot[1]+type[2，大端]。导入 MF1 使用 4000：起始块[1]+16*n 数据；EM410X 使用 5000，5 字节。8 槽类型通过 1019（32 字节）、启用标志通过 1023（16 字节）、当前槽通过 1018（1 字节）获取。

学习扩展保留 1100..1108：状态、配置写入、UTC／时区、明确训练、清除样本、预测、样本摘要、保存、配置读取。布局与 alpha.3 一致，细节见代码 `software/script/chameleon_learning.py` 的解码与编码函数。成功 0x68，参数错误 0x60，场中繁忙 0x6a，无可用学习上下文 0x6c，存储失败 0x70。

状态仍为 30 字节：协议 1、模式、当前槽、建议槽、分数、差距、原因、证据、样本数、时间有效、HF/LF 场、待切槽、dirty、扫描中、存储错误、UTC[4]、自动切换计数[4]、丢弃会话计数[4]、可用槽 bitmask、反馈数。slot 内部为 0..7；无槽 255。原因 manual_hold 现在表示尚未完成刷卡的手动选择锁定，**不再表示 30 秒超时**。

模型配置仍为 12 字节，权重默认 BLE/reader/time=60/30/10。读卡模式的卡片管理不产生训练标签。原私有 1200..1202 卡片命令不再保留，应使用当前官方命令；学习记录本身不迁移编码。

官方读卡器支持和密钥恢复数据采集命令来自 README 记录的基准源码；算法是否适用于某张卡由卡片 PRNG 与已有密钥决定。
