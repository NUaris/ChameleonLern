# 混合学习与选卡流程（v0.2.0）

纯 C 核心保留 v0.1.0-alpha.2／alpha.3 的版本 1 模型格式：32 个样本，最多 6 个 BLE 标识、8 个读卡器 token、时间特征。FDS file=0x4C10、key=1，2208 字节，CLRN、大端编码、CRC32；该记录不与官方卡片、设置或配对记录重叠。卡片和卡槽使用当前官方布局，旧私有 0x4C00..0x4C03 只保留在 Flash，不自动解释或删除。

## 手动优先

A/B 切卡及模拟模式的明确选槽产生手动选择。A/B 是实际刷卡意图，数据加载后会恢复 TAG 模式；GUI／CLI 选槽仍保留已有读卡模式。最后一个管理连接关闭、且场发生器未启用时，自动恢复 TAG 模式。无场后应用请求，锁定所选卡直到它完成下一次刷卡；超时不能释放这一选择。HF/LF 场中禁止切卡，按键请求排队到离场后执行。手动选择当前卡也会重新建立锁定。

手动刷卡结束且所有场都消失 350 ms 后，主循环以所选槽标注最近会话，再释放手动锁定。按钮选择前的 BLE／时间可作为初始标签，完成后的认证／RATS 等交互用于补充标签。自动预测不产生训练标签。OFF 模式仍响应手动选择，但不学习也不自动切换。

## 无手动选择时

AUTO 在无场、离场至少 350 ms、未被手动锁定时按学习结果预选卡；自动切换间隔至少 10 秒。默认最低分 70、领先第二候选 12、相似反馈至少 2 次；模糊、无上下文、记录不存在或卡槽未启用时不强制切换。OBSERVE 仅给建议。全新模型默认 AUTO，已有模式设置保留。

BLE 采用稳定广播身份和 RSSI 平滑，20 秒过期，剔除单独的通用编号和旋转隐私地址。读卡器 token 仅记录寻卡／级联／认证类型与块号／RATS／粗粒度时序，不保存 UID、密钥或 nonce。时间无法独立触发选卡。HF 命令采集在首次交互后才可用，推荐用于离场后的下一次接近，不能在正在进行的认证中途换卡。LF 暂无读卡器独立身份特征。

主动进入读卡模式时清除旧的模拟场状态；硬件停用时不一定触发离场回调，被中断的认证不会被标注为完成交互。

模型、卡槽是不同 FDS 记录，没有跨记录事务；每 30 秒空闲保存脏模型，失败保留脏标记，CLI save 可显式保存。卡片存储、加载、模拟与 USB 灯效由官方实现负责；平台适配将旧模型写入单位从 word 转为官方 API 的 byte，并关闭所有成功打开的 FDS 记录。

## 空闲休眠与射频优先（alpha.2）

AUTO／OBSERVE 遵守官方的 USB、BLE 连接、活动场和空闲超时规则，不再无条件保持 System ON。入睡前停止被动扫描并保存脏模型；保存失败会重试，低电量强制关机不受它阻止。手动锁定用官方 `.noinit` 保留 RAM 中的 12 字节记录（magic、slot、反码）跨 System OFF 保存，只在正常睡眠唤醒且保存卡槽匹配时恢复；冷启动或普通复位丢弃，不改变 CLRN 模型或官方卡片布局。

场检测 IRQ 在接收准备好后立即停止扫描；扫描启动前后再次检查 RF 场。寻卡／级联／RATS、Classic 首次与 nested 认证的学习时钟采样在官方回应设置后执行。切卡、写模型和休眠还检查 HF 硬件场寄存器，避免 IRQ 尚未同步软件标志时打断交流。

深度休眠不扫描环境；先按键唤醒并等待扫描才能按 BLE 环境预选。直接被 RF 场唤醒时先使用保存的当前卡，不在认证中途换卡。重启后 UTC 失效，需要重新同步。
